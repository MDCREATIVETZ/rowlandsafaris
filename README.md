# Rowland Safaris website redesign demo

This is an independent static multipage demo prepared for presentation to the business owner. It does not modify the current live website.

## Open locally

Open `index.html` with Live Server in Cursor, or upload all files and folders to the root of a GitHub repository.

## Before production launch

- Replace the text logo with the official high-resolution Rowland Safaris logo.
- Replace demonstration Unsplash photos with owner-approved images.
- Confirm every package itinerary and add prices only after the company approves them.
- Connect the enquiry forms to email or a secure form service if WhatsApp-only enquiries are not preferred.
- Add the final domain to canonical and social metadata.

## Structure

- HTML pages are in the root folder.
- Shared styles are in `css/style.css`.
- Mobile navigation, gallery lightbox, current year, and WhatsApp forms are in `js/main.js`.
